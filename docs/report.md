# 短报告：预训练模型推理与评价

日期：2026-09-25至26。本报告依据已完成的本地运行；不是论文训练结果复现。

后续已新增MPU和用户上传UBFC的接触PPG对比与带GT视频，见[MPU补充报告](gt_followup.md)和[UBFC报告](ubfc_report.md)。
以下内容保留为此前MIT无GT阶段的记录；其中“无真值”仅指MIT阶段。

## 已完成与主要观察

1. 建立独立本地项目，记录Linux/GPU/Python/CUDA环境、官方代码commit、权重来源和校验和。
2. MTTS-CAN的官方HDF5确实包含脉搏与呼吸双输出。更关键的是发现并验证一个兼容性陷阱：
   新版TensorFlow中，私有Keras按拓扑加载可能不报形状错误，却把同形状卷积权重交换到错误支路。
   仅通过“load_weights没报错”不足以证明匹配。本项目增加逐层名称/张量验证，切换公开Keras导入；
   与checkpoint内部保存的完整模型图重建结果对照，前向最大绝对差为0。
3. 使用MIT作者公开提供的原始面部视频完成有效双输出推理。301源帧，30Hz，保留300个模型输出；
   原始差分、积分、去趋势、滤波、时间戳与频谱均保存。
4. 固定10秒Hann频谱的脉搏峰为0.9Hz，得到**HR预测54次/分**；呼吸峰为0.3Hz，
   得到**RR探索性预测18次/分**。波形可见周期变化，但这并不能证明它们是真实生理变化。
5. BigSmall两个官方仓库均提供多任务权重，模型返回12个AU logits及脉搏、呼吸两路差分。
   核查到训练脉搏为POS伪标签，呼吸为呼吸带波形；两者与BP数值测量不是一回事。
   两份权重均在各自官方模型中严格加载并通过前向检查，实际参数不同，不能互换结果。
6. BigSmall使用Toolbox Fold1权重完成同一视频推理：按PTS映射到25Hz，保留249个输出（9.96秒），
   最大取帧时间偏差13.333毫秒。固定矩形窗与补零FFT得到**HR预测99.6次/分、RR探索性预测11.7次/分**。
   两个方法预测明显不同；无真值且协议不同，无法判断谁更准确。补零频率网格不代表真实精度提高。

MTTS-CAN图 (local artifact: `results/mtts_mit_face_demo/predictions.png`)、

## 不能得出的结论

- 没有同步真值，未计算真实MAE、RMSE或相关系数，不能声称测量准确。
- 十秒对应约6/min的原始频率分辨率，呼吸最低频率的一个周期甚至长于整个片段；RR不可靠。
- 当前只有一个压缩视频、一个固定裁剪，不能说明跨受试者、肤色、运动、光照或设备泛化。
- 未训练、未微调、未完整重跑论文评测集，不能宣称复现论文性能。
- 不评价血压、血氧、皮肤温度、瞳孔或心理状态。AU头也不作心理解释。
- MTTS-CAN与BigSmall使用不同帧率、频带和谱估计方式，本阶段不排名。

## 真值评价条件

COHFACE同时有视频、BVP和呼吸，但官方Zenodo文件需要机构授权；未代注册、申请或签署协议。
LGI-PPGI仅有脉搏参考，旧大包下载不可用，本阶段没有下载完整数据集。
通用评价脚本已用合成信号验证时钟偏移、窗口和缺标签处理；这是软件测试，不是准确性证据。

## 下一步最值得做的一组实验（不训练）

用户自行获得COHFACE授权后，先用一个60秒带BVP/呼吸真值的样本验证读数、时间同步、单位及裁剪。
然后预先固定一个小型测试清单，例如5名受试者各2种照明条件，保留失败样本，记录总下载量后
只取所需条目。选择清单和全部参数应在看误差前完成。

对每个方法独立固定与其输入相符的帧率处理；先报告原生帧率变化带来的限制。
HR用30秒非重叠窗，RR用60秒非重叠窗，保存预测/真值对齐图、MAE、RMSE、偏差及有效窗口数。
波形相关必须注明PPG/呼吸带定义、归一化、符号和固定时延，不从测试数据优化对齐。
最终按受试者汇总，报告失败模式；只有确认训练来源、测试划分和评价协议可比后才做方法比较。
